# Redirections

Cette branche ne contient que des pages de redirection vers **https://mge-energie.fr**, l'adresse actuelle du site.

GitHub Pages est configure pour servir cette branche, afin que les anciens liens — notamment celui de la fiche Google Business — continuent de fonctionner.

Le site lui-meme vit sur la branche `main` et est deploye par Cloudflare Pages.
